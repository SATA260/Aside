# Aside 产品方案 v0.1

## 1. 定位

Aside 是一个陪考研学生自习的桌面计时器：开始之后，电脑退到一旁，只安静地显示时间，同时如实记下每一段学习。

两条设计原则贯穿所有功能：

- **只记录，不评判。** 数据只展示做到了什么，不展示差了多少。没有失败、没有断签、没有红色。
- **电脑是背景，不是主角。** 计时页要在房间另一头也能看清，但绝不催促人。

平台：Windows 10/11、macOS 12+。技术栈：Tauri 2 + React + TypeScript + SQLite。

## 2. 功能清单

### 2.1 科目

- 预置五个科目：政治、英语、数学、专业课、其他。每个科目有名称和一个颜色。
- 开始页默认选中“其他”，不选科目也能直接开始。点“再来一段”时沿用上一段的科目。
- “其他”是兜底科目，可以改颜色，但不能改名和归档。
- 可以新增、改名、改颜色、排序、归档。归档后不出现在开始面板，但历史记录保留。
- 没有“删除科目”，只有归档，避免误删历史数据。

### 2.2 计时

| 模式 | 行为 |
|---|---|
| 倒计时 | 预设 25 / 45 / 60 / 90 分钟，可自定义 1 分钟到 24 小时，按“小时 + 分钟”填写。默认 45 分钟 |
| 正计时 | 不设时长，一直累加，适合做整套卷子。满 24 小时自动结束，避免忘了关 |
| 模考 | 按考研真题时长倒计时，四科默认都是 180 分钟。结束后可以填分数，也可以跳过 |

- 时长不到 1 小时时显示“分:秒”，1 小时及以上显示“时:分:秒”。
- 开始前选择：科目（默认“其他”）、这一段要做什么（可不填）、显示方式（默认全屏，也可以选浮窗）。背景画面和背景音在开始页右侧的氛围面板里切换，见 2.12。
- 计时中可以暂停和继续。暂停的时间不计入学习时长。
- 计时中可以在全屏和浮窗之间随时切换。
- **提前结束不算失败**：实际学了多久就记多久，界面上只说“已记下”。少于 1 分钟的不记录。
- 计时由后端按“开始时间 + 累计时长”计算，不依赖界面定时器。电脑睡眠或锁屏后回来，时间依然准确。

### 2.3 补记与备注

- 在“记录”页手动添加一段学习：科目、日期、开始时间、时长、备注。
- 补记的条目带一个小标记，和计时产生的条目区分开，但统计时同等对待。
- 已有的记录可以编辑和删除。
- **备注**：每一段记录都可以加一条备注，默认不加，最多 200 字。
  - “任务”是开始前写的“这一段要做什么”，“备注”是事后写的，比如“第 3 题没想通，明天问”。
  - 结束页有一个不显眼的“加个备注”，点开才出现输入框，不点就不会打扰。
  - 也可以在某一天的记录里随时添加或修改。
  - 备注不会出现在周报卡片上。

### 2.4 全屏计时页

- 覆盖所有显示器。主屏显示计时内容，其余屏幕显示同色背景，没有内容。
- 页面元素：科目和任务（左上）、当前时刻（右上）、大号时间（居中）、天际线进度（底部）、每日一句（最下方）。
- 背景用氛围面板里选的背景画面，默认是天色渐变。
- 大号时间默认显示倒计时的剩余时间，正计时则显示已学时长。设置里可以改成“始终显示已学时长”，减少紧迫感。
- 鼠标静止 3 秒后，所有控件淡出。移动鼠标时，天际线附近淡入一行文字按钮：暂停、氛围、缩成浮窗、结束。它们没有底框和边框，和每日一句一样直接写在背景上；当前激活的项下面有一个小光点。点“氛围”后的样子见 2.12。
- 计时期间阻止系统休眠和屏保。
- 防烧屏：内容整体每隔几分钟漂移几个像素，肉眼察觉不到。

### 2.5 浮窗：Q 版形象

浮窗默认是一个站在屏幕角落的 Q 版小人，身边带一个显示时间的小气泡。形象可以切换，第一版内置一只“企鹅连体服”小人，见第 8 节。设置里也可以换成简洁的胶囊样式，适合看网课时不想分心的人。

- **窗口**：透明、无边框、置顶。按住形象、时间气泡或窗口里的空白处可以拖到任意位置，松手后记住。
- **气泡**：显示剩余时间（正计时则显示已学时长），底边有一条细进度线。
- **交互**：可以拖动，并记住上次的位置。鼠标悬停时，气泡里出现暂停、氛围、展开到全屏、结束四个按钮。
- **状态和动作**：

| 计时状态 | 小人在做什么 |
|---|---|
| 专注中 | 低头看书或写字，偶尔眨眼、翻页 |
| 暂停 | 伸懒腰或喝口水 |
| 最后 5 分钟 | 抬头看一眼钟，不催促 |
| 时间到 | 开心地挥手，气泡显示“记下啦” |

- 上表是通用的四种状态，每个形象用自己的方式演。比如企鹅是扑腾两只小翅膀。
- 动作都放得很慢，幅度很小，不会在余光里抢注意力。系统开启“减少动态效果”时只保留眨眼。
- 形象用逐帧动画，形象包的格式见第 8 节。

简洁胶囊样式（约 240×56）：显示科目色点、科目名和时间，底边有一条细进度线，交互和小人一样。

### 2.6 结束

- 倒计时结束：屏幕颜色缓慢变亮，同时响起柔和的铃声。铃声从很小的音量开始，30 秒内渐强，最多重复 3 次。在电脑前做任何操作都会让铃声停下。
- 结束页显示：“这一段学了 50 分钟，已经记下了。”以及科目和任务。按钮只有“再来一段”和“回到电脑”，下方有一个淡淡的“加个备注”。
- 模考结束时，结束页额外显示一个可选的分数输入框。

### 2.7 减压相关

- **每日一句**：内置约 120 句温和、不打鸡血的话，每天换一句，显示在全屏页底部和结束页。所有句子都由我们自己撰写，避免版权问题。
- **不做连续打卡**：统计页显示“本周学了 5 天”“本月学了 21 天”，断一天也不清零，不出现“连续天数”。
- **考研倒计时**：默认关闭。在设置里填考试日期并打开后，只在开始面板顶部显示一行小字，不出现在全屏页。
- **背景音**：内置雨声、咖啡馆、篝火、白噪音四种，也可以导入自己的音频。可单独调节音量，循环播放，默认关闭。在氛围面板里切换，见 2.12。

### 2.8 记录与统计

- **今日**：今天学了多长时间，以及各科目的占比条。
- **趋势**：本周和本月的每日柱状图，按科目分色堆叠。可以设每日目标；设了以后柱子上会出现一条淡淡的参考线，没有达标提示。
- **热力图**：最近 16 周，颜色深浅代表学习时长，没学的日子留空，不标红。
- **某一天的记录**：
  - 记录页顶部有日期切换（‹ 10月13日 ›），也可以点开日历任选一天。点热力图的格子或趋势图的柱子，同样会跳到那一天。
  - 页面上方是一条 0 点到 24 点的时间轴，每段专注按科目颜色画成色块，没学的时间留空。
  - 下方是这一天所有时间段的列表，每条包括起止时间、科目、任务、时长、备注，补记的带标记。点击可以编辑或加备注。
  - 跨过零点的一段专注，统计时按零点拆到两天，记录本身仍是一条。
- **周报卡片**：每周一打开 app 时，提示可以查看上周的周报。卡片是一张竖版图片，包含总时长、各科目占比、7 天分布和一句话，可以保存为 PNG 分享给研友。

### 2.9 系统集成

- **托盘 / 菜单栏**：
  - macOS 菜单栏直接显示剩余时间，比如“32:48”。
  - Windows 托盘图标无法显示文字，改为在图标上画一圈进度，鼠标悬停时显示剩余时间。
  - 托盘菜单：开始或结束、显示主窗口、退出。
- **全局快捷键**：
  - 开始或结束：macOS 为 `⌥⌘S`，Windows 为 `Ctrl+Alt+S`。
  - 全屏和浮窗互相切换：macOS 为 `⌥⌘M`，Windows 为 `Ctrl+Alt+M`。
  - 两个快捷键都可以在设置里修改。
- **开机自启**：默认关闭，在设置里打开。开机后只出现在托盘，不弹出主窗口。
- **数据只存本地**：不需要账号。设置里有“打开数据文件夹”和“导出备份”两个按钮。

### 2.10 界面音效

所有能点的地方都有一声很轻的反馈音，让操作有手感，但不吵。

| 场景 | 声音 |
|---|---|
| 普通按钮、科目和时长选择 | 很短的木质轻敲声 |
| 开关、分段切换 | 两声更轻的“嗒” |
| 开始专注 | 两个由低到高的柔和音 |
| 暂停 / 继续 | 一声轻响，继续时音高略高 |
| 结束、已记下 | 一声柔和的铃音 |
| 删除确认 | 一声略低的闷响 |

- 每个声音都在 150ms 以内（铃音除外），没有尖锐的高频。
- 设置里有独立的开关和音量，默认打开、音量 40%，和铃声、环境音分开调。
- 用全局快捷键开始或结束时，也会播放对应的声音。
- 声音用 Web Audio 实时合成，不需要素材授权，几乎不占体积。如果合成的质感不够好，再换成录制的音效。

### 2.11 勿扰

两个系统都没有公开接口让 app 直接打开勿扰或专注模式，所以这样处理：

- **macOS**：在设置里引导用户在“快捷指令”里创建两个指令，分别用来打开和关闭专注模式。计时开始和结束时，app 通过 `shortcuts run` 调用它们。
- **Windows**：计时开始时提示一次“可以按 Win+N 打开勿扰”，并提供“不再提示”选项。

### 2.12 氛围面板

开始页右侧固定一栏“氛围”，三样东西都是点一下就换，不用进设置：

- **预览**：顶部一张缩略图，实时显示全屏页换上当前画面后的样子。字色跟着画面走，浅色画面用深色字。
- **背景画面**：全屏页的背景。
  - 内置五种：天色（默认，渐变）、雨窗、台灯、星夜、晨雾。
  - 可以选一张自己的图片，自动压暗并轻微模糊，保证时间看得清。
  - 内置画面优先用 CSS 渐变和少量粒子动画实现，体积小；需要插画的场景之后再补。
- **背景音**：关、雨声、咖啡馆、篝火、白噪音、自己导入的声音，最后是一个“＋ 导入”，旁边一个音量滑块。
  - **导入**：
    - 支持 mp3、m4a、wav、flac。
    - 选好文件后，复制一份到 app 的数据文件夹，之后原文件移走或删掉也不影响。
    - 单个文件最大 200MB。
  - **命名**：默认用文件名，可以改，比如“宿舍风扇”“妈妈做饭”。
  - **循环**：
    - 短于 10 分钟的音频解码后无缝循环，没有断点。
    - 更长的边播边读，结尾和开头做 2 秒交叉渐变。
  - **音量对齐**：导入时自动测一下响度，调到和内置声音差不多大，不会突然很吵。可以在设置里关掉。
  - **管理**：右键或长按导入的声音，可以改名、删除。导入的声音在列表里带一个小小的“我的”标记。
- 画面和声音都会记住上次的选择。界面本身固定用夜读配色，不再单独选风格。

#### 专注中也能切换

开始专注以后，随时可以换背景画面和背景音，计时不受任何影响。

| 在哪里 | 怎么打开 | 能换什么 |
|---|---|---|
| 全屏计时页 | 移动鼠标，控制条上点“氛围” | 背景画面、背景音和音量 |
| 浮窗 | 鼠标悬停，点气泡上的“氛围”图标，旁边弹出小面板 | 背景音和音量 |

- **全屏页不弹面板，选项直接写在背景上**：
  - 点“氛围”后，大号时间稍微上移。时间和天际线之间淡入两组文字：左边“画面”，右边“声音”。
  - 没有底框、边框和缩略图，字体、颜色和每日一句同一套。当前选中的项颜色更亮，下方有一个和天际线光点一样的小光点。
  - 声音组下方是一条细线加一个圆点，用来调音量，样子和天际线呼应。
  - 鼠标移到某个画面上就直接预览：背景本身就是预览图，移开恢复，点击才算选定。声音只在点击时切换，避免鼠标划过时一阵乱响。
  - 切换成功后，顶部正中淡入一行小字，比如“换成了 雨窗”，2 秒后淡出。
  - 鼠标静止 3 秒后，这两组文字和按钮一起淡出，页面回到只有时间的样子。
- **快捷键**：全屏页里不用打开面板也能直接换。
  - `B`：换下一个背景
  - `N`：换下一个声音
  - `↑` / `↓`：调背景音音量
  
  按快捷键切换也会出现同样的顶部小字提示。快捷键提示用很淡的小字写在右下角，只在控件显示时出现。
- **过渡要柔和**：
  - 背景画面用 1.2 秒交叉淡入淡出。
  - 背景音用 2 秒交叉渐变，不会突然断掉再响起。
- **专注中换的就是正式设置**：没有“只在这一段生效”的临时状态。回到开始页时，氛围面板显示的就是刚才换过的选择，下一段沿用。

### 2.13 显示方式

开始专注时默认全屏，也可以选浮窗。按住形象、时间气泡或窗口里的空白处，就能把浮窗拖到任意位置。网课模式已去掉。

## 3. 界面

主窗口约 1040×680，左侧窄导航，包含四页。外观稿见 `docs/mockups/index.html`，用 `?v=night|nightmood|mist|end|start|mini|lecture|video|day|stats|card` 切换画面，截图在 `docs/mockups/shots/`，二次元形象的概念图在 `docs/mockups/assets/`。

| 页面 | 内容 |
|---|---|
| 开始 | 左侧：选科目、方式、显示方式、时长，填任务，以及“开始专注”按钮。右侧：氛围面板（预览、背景画面、背景音） |
| 记录 | 日期切换、当天时间轴和时间段列表（补记、备注在这里）、今日概览、趋势、热力图、周报入口 |
| 科目 | 科目管理 |
| 设置 | 主题、时间显示方式、浮窗样式、铃声、界面音效、环境音、快捷键、自启、勿扰、考研日期、数据 |

独立窗口：全屏计时页（每个显示器一个）、浮窗、结束页（复用全屏窗口）。

### 主要流程

```
托盘 / 快捷键 / 开始页
  → 选科目和时长 → 开始专注
  → 主窗口隐藏，全屏页或浮窗出现
  → （可以随时暂停、切换显示方式、提前结束）
  → 时间到：柔和铃声 → 结束页
  → 再来一段（回到开始页并保留上次的选择）/ 回到电脑（关闭全屏）
```

## 4. 视觉规范

### 4.1 设计签名：天色

全屏页的背景不是纯色，而是一片缓慢变化的“天色”渐变。底部的进度不用圆环，而是一条横贯屏幕的细线，像天际线；已经过去的部分会微微发亮，前端有一个柔和的光点。

整个页面没有任何一闪一闪或跳动的元素。秒数变化时用 200ms 的淡入淡出，而不是直接跳变。

主题选“跟随天色”时，配色会按真实时刻自动切换：清晨用雾蓝，白天用晴灰，傍晚用暮紫，夜里用夜读。

### 4.2 主题配色

| 主题 | 背景 | 背景渐变终点 | 文字 | 次要文字 | 强调色 |
|---|---|---|---|---|---|
| 夜读（深） | `#10151F` | `#1E2638` | `#D7DEE8` | `#7D889B` | `#9FB7D9` 月光蓝 |
| 竹青（深） | `#121B17` | `#1D2A24` | `#D5E0D8` | `#7F9187` | `#8FB8A0` |
| 雾蓝（浅） | `#E4E9EF` | `#F1F0EC` | `#27303D` | `#7A8596` | `#5B7BA6` |
| 暮紫（浅） | `#E9E4EC` | `#F3E9E3` | `#2F2A36` | `#857B8E` | `#8A6FA3` |

预置科目颜色都是低饱和色：

- 政治 `#C98B7B`
- 英语 `#7FA3C7`
- 数学 `#8DB59A`
- 专业课 `#C7AE7F`
- 其他 `#A3A9B4`

### 4.3 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 计时数字 | Manrope 200 | 极细、等宽数字（tabular-nums），超大字号下依然安静 |
| 句子、科目、任务、周报标题 | 霞鹜文楷 屏幕版 | 有手写笔记感，和考研的纸笔世界呼应。按常用 7000 字子集打包，约 3–4MB |
| 界面文字 | 系统字体（苹方 / 微软雅黑） | 按钮、设置项等，不额外打包 |

两款字体都使用 SIL OFL 开源授权，可以免费商用。

### 4.4 动效

- 进入全屏：主窗口淡出，计时页从背景色中淡入，用时 600ms。
- 天色背景：一个 60 秒的渐变缓慢循环，几乎察觉不到。
- 结束：背景在 3 秒内提亮约 15%，再淡入结束页文字。
- 系统开启“减少动态效果”时，关闭所有循环动画，只保留淡入淡出。

## 5. 文案原则

- 不出现：失败、未完成、落后、只学了、又、还差。
- 结束时说“已经记下了”，不说“任务完成”或“任务中断”。
- 统计页说“本周学了 5 天”，不说“本周缺勤 2 天”。
- 每日一句示例：“慢慢来，比较快。”“今天也坐下来了，这就很好。”“题会做完的，不急在这一道。”

## 6. 技术方案

### 6.1 结构

```
Rust 后端（src-tauri）
  timer    计时状态机：idle → running ⇄ paused → finished
           只存 started_at、accumulated_ms、planned_ms，每秒向前端广播一次
  windows  创建和销毁全屏窗口（每个显示器一个）、浮窗、主窗口、网课窗口
  lecture  网课窗口里的课程网页：一个窗口放两个 webview（课程网页 + 侧栏），
           需要开启 Tauri 的 unstable 特性，锁定 Tauri 小版本防止 API 变动；
           “只看视频”通过向课程网页注入脚本，找到正在播放的最大 video 元素并铺满
  store    SQLite（rusqlite），科目、记录、模考、设置
  system   托盘、全局快捷键、自启、阻止休眠、勿扰快捷指令
React 前端（src）
  pages    开始、记录、科目、设置
  overlay  全屏计时页、结束页
  mini     浮窗（小人和胶囊两种样式）
  shared   主题、字体、图表、音频、界面音效
```

### 6.2 数据表

```sql
subjects(id, name, color, sort, archived_at, is_fallback)  -- is_fallback 只有“其他”为 1
sessions(id, subject_id, mode, planned_sec, started_at, ended_at,
         focused_sec, task, note, source)  -- mode: countdown | countup | mock；source: timer | manual
mock_scores(session_id, score, full_score)
sounds(id, name, file, builtin, gain_db, created_at)  -- 导入的音频文件放在数据文件夹的 sounds/ 下
settings(key, value)
-- 形象包不进数据库，直接按文件夹扫描数据文件夹的 characters/ 和内置目录
```

### 6.3 依赖

- Tauri 官方插件：global-shortcut、autostart、window-state、dialog、fs、opener。
- Rust：rusqlite（自带 SQLite）、keepawake（阻止休眠）。
- 前端：React、Vite、Zustand（状态管理）、柱状图和热力图都用 SVG 和色块画、html-to-image（导出周报）。
- 资源：环境音和铃声使用 CC0 授权的素材，打包进 app。

## 8. Q 版形象（可切换）

### 8.1 切换

- 在设置的“浮窗样式”里选：企鹅（默认）、胶囊（不显示形象）、自己导入的形象。
- 专注中也能在浮窗的氛围小面板里换，和背景音一样立即生效。
- 所有形象共用同一套动画规格：Q 版，头身比大约 2:1；逐帧动画，每个状态 4 到 8 帧循环，每秒 6 到 8 帧，刻意放慢。

### 8.2 第一版内置：企鹅小人

“咕咕嘎嘎”现在最流行的那只企鹅，是网友用 AI 把《明日方舟：终末地》的女管理员改成企鹅造型的二创图。它有三层版权问题：

- 角色形象属于鹰角。
- 2026 年 7 月，字节跳动旗下公司登记了“咕咕嘎嘎”2D/3D 形象的美术著作权。
- 最早做出这张图的 UP 主也主张过权利。

Aside 要打包发给别人用，直接用那张图有侵权风险。所以内置的是**我们原创的企鹅小人**：保留“穿企鹅连体服、呆萌、会嘎嘎叫”的感觉，但造型、配色、脸都是自己的。

- **造型**：深青蓝色企鹅连体服，帽兜是企鹅头，橙色小嘴在帽檐上，脚上是企鹅拖鞋，短翅膀袖子；小人戴圆眼镜，表情安静。
- **配色**：只用青蓝 `#3E4A63`、米白、浅橙 `#E0A060`（只用在嘴和脚）。不用黑黄配色，避免和终末地管理员撞色。
- **动作**：专注时看书并轻轻摇晃；暂停时举起两只翅膀伸懒腰；最后 5 分钟侧头看钟；时间到时扑腾翅膀，气泡里冒出“嘎嘎！”。
- **叫声**：时间到时可以播一声“嘎嘎”，默认关闭。声音由我们自己录或合成，不用网上流传的那段音效。
- **名字**：形象名叫“嘎嘎”。“咕咕嘎嘎”只是拟声词，文案里可以出现，但不作为形象名或商标使用。
- 概念图见 `docs/mockups/assets/penguin-original.jpg`，只作为交给画师的参考，不直接当正式素材。

### 8.3 形象包格式

每个形象是一个文件夹，内置形象和导入形象用同一种格式：

```
penguin/
  character.json   名字、作者、版本、显示尺寸、每个状态的帧数和每帧时长
  focus.png        专注中
  pause.png        暂停
  last5.png        最后 5 分钟
  done.png         时间到
  blink.png        只眨眼（减少动态效果时用）
  preview.png      选择列表里的缩略图
  done.mp3         可选，时间到的叫声
```

- 每个状态一张横向排列的 PNG 序列图（sprite sheet），透明背景。单帧 360×440 像素，按 2 倍图绘制，显示时缩小到 180×220。
- 换形象、修素材都只动文件，不改代码。

### 8.4 导入形象

- 设置里点“导入形象”，选一个形象包文件夹或 `.zip`。导入后复制到数据文件夹的 `characters/` 下。
- 导入时检查格式：缺状态图、帧数对不上、图片过大，都会明确提示是哪个文件有问题。
- 导入的形象只给你自己用，Aside 不提供分享和下载形象的渠道。用别人作品做成的形象包，版权责任在导入的人。
