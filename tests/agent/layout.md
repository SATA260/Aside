# 各种屏幕大小下的布局

`pnpm test:e2e` 里的 `layout.spec.ts` 只能检查“在不在屏幕里、有没有重叠、有没有居中”，好不好看要 agent 看照片判断。改了主窗口任何一页或全屏页后走一遍。

## 拍照

开着 `pnpm dev:bridge` 和 `pnpm dev`，然后：

```bash
node scripts/shots.mjs /tmp/aside-shots              # 全部
node scripts/shots.mjs /tmp/aside-shots settings     # 只拍某几页：start subjects settings focus end mini
```

主窗口拍 880×600（最小）、1040×680（默认）、1440×900、1920×1050；全屏页拍 1280×720、1440×900、1920×1080、2560×1440 和竖屏 1080×1920。拍全屏页时会在开发数据里记下一段 45 分钟的数学。

## 看什么

- 主窗口：
  - 880×600 下开始页一屏放得下，开始按钮不贴底。
  - 窗口变大后内容在侧栏右边居中；开始页的表单上下也大致居中，不会只占左上角一小块。
  - 设置页 1480 宽以上分两栏，两栏顶端对齐、高度差不多；更窄时一栏居中。
  - 任何宽度下“跟随天色”等风格名都在一行；行里左边的说明可以折行，但右边的控件不被挤变形。
- 全屏页：
  - 不同屏幕上看起来是同一张图等比放大：上边科目和时刻、中间大数字、下面文字按钮、地平线和一句话。
  - 2560×1440 上小字（科目、按钮、地平线两端时刻）明显比 1280×720 上大。
  - 竖屏上大数字不贴边；“小时:分:秒”三段也放得下（模考 3 小时时看一眼）。
  - 任务写满 50 个字时，左上角截成省略号，不压到右上角的时刻。
- 结束页：标题、按钮、备注框跟着屏幕等比放大；竖屏上备注框不出屏幕。
